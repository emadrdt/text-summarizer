# 📝 خلاصه‌ساز و پرسش‌گر متن (Doc Summarizer & Q&A)

یک ابزار ساده و کاربردی که متن کاربر رو می‌گیره، با استفاده از مدل‌های هوش مصنوعی (از طریق **OpenRouter API**) خلاصه‌ش می‌کنه و به سوالات کاربر درباره‌ی متن جواب می‌ده.

این پروژه دو نسخه داره:
- **نسخه‌ی ترمینال (CLI)** — اجرا در خط فرمان
- **نسخه‌ی وب (Streamlit)** — رابط کاربری گرافیکی توی مرورگر

---

## 🎯 چرا این پروژه ساخته شده؟

این پروژه به‌عنوان بخشی از مسیر یادگیری پایتون پروژه‌محور ساخته شده و این مهارت‌ها رو پوشش می‌ده:

- فراخوانی API و احراز هویت با `Authorization: Bearer`
- مدیریت امن کلید API با `.env` (بدون قرار دادن کلید در کد)
- کار با کتابخانه‌ی `requests` و پاسخ‌های JSON
- ساخت رابط کاربری وب با `Streamlit`
- طراحی پرامپت (Prompt) برای خلاصه‌سازی و پرسش‌وپاسخ

## 🚀 راه‌اندازی و اجرا

### ۱. کلون یا دانلود پروژه

```bash
git clone <آدرس-ریپو>
cd doc-summarizer
```

### ۲. نصب کتابخانه‌ها

```bash
pip install -r requirements.txt
```

یا به‌صورت دستی:

```bash
pip install requests python-dotenv streamlit
```

### ۳. ساختن فایل `.env`

یه فایل به اسم `.env` کنار کد بساز و کلید API خودت رو داخلش بذار:

```
OPENROUTER_API_KEY=sk-or-xxxxxxxxxxxxxxxx
```

> ⚠️ **مهم:** فایل `.env` رو هرگز روی گیت‌هاب آپلود نکن. مطمئن شو توی `.gitignore` هست:
> ```
> .env
> ```

### ۴. اجرا

**نسخه‌ی ترمینال:**
```bash
python main.py
```

**نسخه‌ی وب (Streamlit):**
```bash
streamlit run app.py
```

بعد از اجرای نسخه‌ی وب، مرورگر روی آدرس `http://localhost:8501` باز می‌شه.

## 📖 نحوه‌ی استفاده

### نسخه‌ی ترمینال:
1. متن رو پیست کن (آخرش یه خط خالی بزن = پایان ورودی)
2. خلاصه به‌صورت خودکار چاپ می‌شه
3. سوالاتت رو بپرس؛ برای خروج `no` تایپ کن

### نسخه‌ی وب:
1. متن رو توی کادر بچسبون
2. دکمه‌ی «✨ خلاصه کن» رو بزن
3. توی بخش پایین، سوالت رو بنویس و «💬 بپرس» رو بزن
